FOR HOLLIE v8.4.3 — CLEAN RECOVERY BUILD

Purpose
-------
This package was rebuilt from the known-working v8.3.4 frontend, then only the v8.4 browser-scanner pieces were added back. It is intended to replace the mixed/merge-conflicted main branch cleanly.

IMPORTANT CLEAN REPLACEMENT
---------------------------
1. In GitHub Desktop, make sure Current branch = main.
2. Abort any merge still in progress.
3. Open the local for-Hollie repository folder in Explorer.
4. DELETE the repository contents EXCEPT the hidden .git folder.
   - Do not delete .git.
5. Copy all files/folders from this package into the repository folder.
6. Return to GitHub Desktop.
7. Commit to main with message: v8.4.3 clean recovery
8. Push origin.
9. In Vercel, redeploy main WITHOUT using the old build cache if that option is shown.
